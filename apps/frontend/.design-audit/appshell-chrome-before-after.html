What changed, in one breath

  • Sidebar collapse — drop the layout-thrashing transition: width .24s; keep the width animation but add an opacity veil so hidden labels do not flash during collapse.
  • Nav-item — replace background-flip with a copper left bar (active) and a copper underline reveal (hover). Both pure ::before / ::after transforms.
  • Topbar — thinner (60px) and a lighter backdrop-filter: saturate(140%) blur(10px) + a copper hairline that brightens at the brand.
  • Command palette — lighter blur, pop-rise enter animation (scale(.98) → scale(1)), refined kbd chips, copper drop on the active item.
  • PriorityActionStrip — raw RGBA blends replaced with --priority-tint-1/-2 tokens; stronger CTA shadow + corner radius for hierarchy.
  • Mobile drawer — translateX-driven slide-in (instead of opacity), refined backdrop with saturate, light-surface copper trim.
  • Skip link — swap top transition for transform: translateY (no layout thrash).
  • Account + Network card — phosphor dot inside the network card; copper dot next to the truncated address on hover/focus.
  • Brand mark — refined drop-shadow (smaller, brighter) + a copper wash halo around the mark only inside the rail.
  • Reduced motion — every entrance + transition is gated by @media (prefers-reduced-motion: reduce).
